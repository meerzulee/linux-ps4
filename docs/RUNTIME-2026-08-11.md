## Fan-driver gap

The active 6.18 patch set only enables the Liverpool PCI IDs in `k10temp` and
`fam15h_power`; it does not contain a PS4 fan driver. rmux added a standard
hwmon driver in
[`d727d1ade392`](https://github.com/rmuxnet/linux/commit/d727d1ade39216099e1ce1df6ac464b1f40f6d6c).
Its source can forward ICC requests to Baikal, but the fan protocol was
live-probed on Aeolia and is documented as compatible with Belize—not verified
on Baikal.

The first Baikal port must therefore be read-only: expose temperature and RPM
only, capture every ICC result over UART, and leave threshold writes disabled.
The full rmux write path is read-modify-write because overwriting factory bytes
can disable the EMC fan loop until a hard power cycle.
